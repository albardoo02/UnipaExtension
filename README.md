# カスパ拡張 (UNIVERSAL PASSPORT RX 向け Chrome 拡張機能)

広島市立大学のカスパ(https://ichipol.g.hiroshima-cu.ac.jp/uprx/)に、次の機能を追加します。

1. **授業資料の一括ダウンロード**
   クラスプロファイル → 授業資料 の一覧の上に「授業資料を一括ダウンロード」ボタンを表示します。
   その授業の全資料(または未確認の資料だけ)の添付ファイルを順番にダウンロードし、
   `ダウンロードフォルダ/カスパ/<授業名>/<第n回資料_資料名>/<元のファイル名>` に保存します。
2. **ブラウザの「戻る」をカスパの戻る操作に置き換え**
   カスパは本来ブラウザの戻るを無効にしています。この拡張を入れると、戻るボタン(や Alt+← / マウスの戻るボタン)で次の順に戻ります。
   - ダイアログが開いていれば閉じる
   - パンくずに一つ前の画面があればそこへ(例: 資料の詳細 → 授業資料一覧)
   - 「戻る」ボタンがあればそれを押す
   - クラスプロファイルの各機能 → クラスプロファイル TOP
   - それ以外 → ホーム(ホームではこれ以上戻りません)

## インストール

1. このフォルダ(`kaspa-ext`)を任意の場所に置く
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
4. 開いているカスパのタブを再読み込みする

## 使い方(一括ダウンロード)

1. カスパにログインし、クラスプロファイル → 授業資料 を開く
2. 一覧の上の「授業資料を一括ダウンロード」を押す(未確認の資料だけにしたい場合はチェックを入れる)
3. 確認ダイアログで OK を押すと、画面が自動で資料を開いては戻りを繰り返します。右下のパネルに進み具合が出ます
4. 終わると「完了しました」と表示されます。途中でやめたいときはパネルの「中止」

### 注意

- **処理中はそのタブも、別のタブのカスパも操作しないでください。** カスパは画面の操作順をサーバー側で厳密に管理しており、割り込むとエラー画面になったりログアウトされたりします。拡張側も授業が切り替わったりエラー画面になったりしたら自動で中断します。
- 開いた資料はカスパ上で既読(未確認が消える)になります。
- 初回は Chrome が「このサイトが複数のファイルをダウンロードしようとしています」と確認することがあります。「許可」を選んでください。ブロックするとダウンロードが始まらず中断します。
- Chrome の設定で「ダウンロード前に各ファイルの保存場所を確認する」がオンだと、ファイルごとに保存ダイアログが出ます。一括ダウンロードの間はオフにしておくと楽です。
- 1ページ(最大100件)に収まらないほど資料が多い授業では、表示中のページの分だけ処理します。

## 設定

ツールバーの拡張アイコンから次を変更できます。

- ブラウザの戻るの置き換え(オン/オフ。変更後はカスパのページを再読み込み)
- 保存フォルダ名(既定は「カスパ」)

## 仕組み(開発メモ)

調査結果の詳細はプロジェクトの `analysis-授業資料ダウンロード.md` を参照。

- カスパは JSF + PrimeFaces。画面遷移はすべて ViewState とトークン付きの POST で、要素 ID は自動採番(`j_idt…`)なので、class・title 属性・見出し文字で要素を探しています。
- 添付ファイルのダウンロードは「準備の Ajax → 隠しボタンでフォームを通常 POST → ファイルが返る」の2段階です。準備を飛ばして POST を再現するとセッションごと無効になるため、**通信は再現せず、画面のボタンを順にクリックする方式**にしています。
- 資料を開くと一覧が詳細に置き換わり、パンくずで戻るとページ全体が再読み込みされます。進行状況は `sessionStorage` に保存し、読み込み後に続きから再開します。
- Ajax の完了は、ページ本体側(`content/ajax-bridge.js`, MAIN world)で `jQuery.active` を `<html data-kaspa-ajax>` に書き出し、拡張側で監視しています。
- ダウンロードは、クリック直前に background に予約(`kaspa:arm`)し、`chrome.downloads.onDeterminingFilename` で予約に一致したものの保存先を付け替えます。予約のない(手動の)ダウンロードには手を出しません。
- 戻るボタン: カスパの `core.js` は読み込み時にダミーの履歴を積み、`popstate` で積み直して戻るを無効化しています。拡張は `popstate` を拾って画面内の戻り先をクリックします。Chrome はユーザー操作なしに積まれた履歴を戻るで飛ばすことがあるため、最初のクリック/キー入力時に履歴を1つ積み直しています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張の定義(Manifest V3) |
| `background.js` | ダウンロードの待ち受けと保存先の振り分け |
| `content/ajax-bridge.js` | ページ側で Ajax 通信中かを書き出す(MAIN world) |
| `content/common.js` | 共通ユーティリティ |
| `content/bulk-download.js` | 一括ダウンロード本体と画面 UI |
| `content/back-button.js` | 戻るボタンの置き換え |
| `content/style.css` | 追加 UI の見た目 |
| `popup.html` / `popup.js` | 設定画面 |
